# ¡A aprender jugando! (Infantil 5 años)

Learning games for 4–5 year olds who can't read yet: everything is voice-guided, with pictures and big buttons.
Single `index.html`, no server, hosted on GitHub Pages. Progress is stored only in each device's browser.

Areas: numbers (to 20), letters (uppercase, alphabet explorer, tracing), colours & shapes, my body (face, body, joints, bones, senses), English, animals & feelings.
Several players with their own stars, stickers and progress; turn mode for playing together; parents' corner behind a multiplication lock.
